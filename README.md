# 校园网自动登录（Edge / Chrome 扩展）

本人是安工程(ahpu)的学生，校园卡是电信，而电信是每天都要登录验证的运营商，忘记的话会在使用中突然断网，非常影响网络体验

该扩展到点自动完成校园网门户认证 —— 不用再手动打开认证页、输学号密码、选运营商。

主要适配 **安徽工程大学（Anhui Polytechnic University）**，门户地址与校内排除域名已按本校预填；
别的学校改几处设置也能用（套路是通用的），不过没试过不太确定。

## 功能

- **定时认证**：设一个时间点（默认早上 `08:00`），到点自动跑一遍。
- **到期检测**（设置里单独勾选，默认关）：按「单次认证有效期」估算到期时刻，到期前 1 分钟
  开始每 5 秒探一次网络 —— **真掉线就立刻重新认证**，还通着就安静收手（不弹窗、不开页面）。
  有效期只是个估算（实测会飘），所以界面上不做倒计时，它只负责决定「什么时候开始盯网络」。
- **认证周期**：`1` = 每天都跑；填 `N` = 每 N 天跑一次 —— 给移动 / 联通这类「认证一次能撑好几天」的运营商用。
- **开机补做**：关机错过了时间点，下次启动补一次（默认开）。另有「一开浏览器就无条件认证一次」的选项，
  但**默认关** —— 到点续期已经覆盖日常场景，用不着每次开浏览器都折腾一遍。
- **打开认证页就自动填**：你自己或计划任务打开认证页，扩展自动填表、选服务、提交。
- **「立即认证」= 真的重认证一遍**：点弹窗里的「立即认证」，会按设置**先点「我要下线」再重新认证**
  （默认开），把在线时长续上 —— 哪怕设备还有网也照做。
- **「主动进网页」永不下线**：点「打开认证页」或自己敲门户地址，只是进页面看一眼 ——
  动手前先用一次网络探测（约 0.1~0.3 秒）确认到底有没有网，**真有网就什么都不做**
  （不下线、不重登，页面照旧开出来），只有确实没网才填表提交。
- **按需认证**（设置里关掉「先下线再认证」）：定时到点时在**前后 30 秒**内密集探测，
  **没网才认证、有网连页面都不开** —— 最省电脑资源的一种配法。
- **全自动走完流程**：填账号密码 → 选运营商（中国电信 / 移动 / 联通）→ 点确定 → 成功收尾。
  中途弹「认证失败」会自动重试，不用管。
- **平时不占资源**：不做实时轮询，后台只在「定时到点」醒来探一下网络；勾了到期检测才会多醒一次。
- **只弹「认证成功」通知**，失败不打扰；认证完自动关掉它自己打开的页面（你自己开的页面不会被动）。
- **不误伤校内其他站点**：教务、图书馆、邮箱这类登录页不会被当成门户。

## 怎么用

1. Edge 打开 `edge://extensions/` → 打开**开发人员模式** → **加载解压缩的扩展** → 选本文件夹
   （zip 要先解压）。
2. 点工具栏扩展图标 → **打开设置** → 填 **账号 / 学号** 和 **密码** → 保存。
3. 设好**认证时间点**（默认早上 8 点）→ 点 **保存并立即认证一次** 试跑一遍。

> **本校同学**：门户地址、备用入口、校内排除域名、服务商（中国电信）都已预填好，
> **只填账号密码就能用**。弹窗里学号打码显示（`3230000001` 显示为 `32******01`）。
>
> **换学校**改三处即可：认证页地址 / 备用入口、排除域名、服务商。

## 效果

- 到点后扩展自己打开门户页 → 填表 → 选服务 → 提交，**几秒内完成**，成功弹一条通知，然后自动关页。
- 已经在线、认证还没到期时，**定时**那一轮会先点「我要下线」再重新认证一次，**让时长真正续上**（可在设置里关掉）。
  关掉之后换成「按需」：到点只密集探一次网络，有网连页面都不开。
- **「立即认证」和「打开认证页」是两种意思**：前者是「给我重新认证一遍」，跟着「先下线再认证」的设置走
  （默认先下线再认证）；后者只是把页面开出来给你看，**绝不碰「我要下线」**。
- 进页面动手前都会先探一次网络：认证没到期就什么都不做（「打开认证页」只把页面开出来），不会被下线。
  （唯一的例外：探测**确认**网关正在拦，说明页面那张「已在线」是缓存的、设备其实没网，这时会走一遍重认证把网络恢复回来。）
- 探测不通或某个入口打不开时，会依次换入口重试；确认确实不需要认证就静默收手，不留空白页。
- 失败最多重试 3 轮后停下，不弹通知（弹窗里能看到状态）。

## 常用设置

| 设置项 | 说明 |
| --- | --- |
| 认证时间点 | 24 小时制，默认 `08:00`，每天到这个点循环 |
| 认证周期（天） | `1` = 每天（默认）；`N` = 每 N 天认证一次 |
| 到期检测 | **默认关**。勾上才按下面的有效期估算到期时刻，快到点密集探一次，真掉线才重新认证 |
| 单次认证有效期 | 一次认证能撑多久，按**小时 + 分钟**填，默认 `47` 小时 `49` 分钟（电信实测约 47:49:20）。两个都填 `0` = 关闭 |
| 浏览器启动时认证 | **默认关**。勾上才「一开浏览器就无条件认证一次」；平时用不上，到点续期和错过补做已经覆盖了 |
| 错过则补偿 | 电脑关机错过时间点，下次启动补一次 |
| 先下线再认证 | **默认开** = 定时 / 开机 / 重试 / **「立即认证」**都强制续期（先点「我要下线」再重认证）；**关掉** = 改成按需认证，只在检测到真掉线时才动手。「打开认证页」/ 自己打开门户页永远不下线 |
| 认证成功后关闭认证页 | 默认开。有结论就关，不挂页面 |
| 系统通知 | 只在认证成功时弹一条 |
| 排除域名 | 万一某个校内站点被误判成门户，把它的域名填这里 |

账号密码只存在浏览器本地（`chrome.storage.local`），不上传任何服务器，扩展不含远程代码；
但密码是**明文存储**的，共用电脑请谨慎。

**仓库内不含任何人的学号 / 密码 / 内网信息。**

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 到点没反应 | 看弹窗里的「下次认证」时间；暂停过就先「恢复定时」 |
| 打开认证页却没自动填 | 检查设置里「进认证页自动填写」是否开着 |
| 一直说认证失败 | 学校可能限制同时在线设备数，或账号密码填错了 |
| 教务系统 / 图书馆被误判 | 把它的域名加到「排除域名」 |
| 提示需要验证码 | 图形验证码无法自动识别，需手动认证一次 |
| 用锐捷 / 深澜客户端、802.1X | 不走网页认证，扩展无能为力 |

## 不在电脑前怎么自动登录

扩展只能活在浏览器里，浏览器没运行时得让系统先把浏览器拉起来：

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup-scheduled-tasks.ps1 -Times "08:00"
```

先加 `-DryRun` 看看会做什么。任务在「用户登录时」运行，电脑需处于已登录状态（锁屏可以，关机不行）。

改完代码在 `edge://extensions/` 点 **重新加载** 生效。
