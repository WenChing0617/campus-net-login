校园网自动登录 · 设置

平时完全休眠，只在设定时间点、浏览器启动、打开认证页这三种时机动作，不做轮询。

账号

密码以明文保存在浏览器本地存储中，只在你的电脑上，不会上传。共用电脑请谨慎。

定时认证

每天到这个点自动认证一次，默认早上 8 点。

1 = 每天（默认）：上面几个时间点每天都跑。填 N（>1）就是每 N 天跑一次：上次认证后中间 N-1 天跳过，到第 N 天才再跑 —— 给「认证一次能撑好几天」的运营商（移动 / 联通）用。手动点「立即认证」不受限制。

认证前会先探测一次：只有检测点返回 204 才认定「已联网、不用认证」。打开后一个地址回 2xx 也算数 —— 只在确认学校不会屏蔽探测地址时才开。

认证方式

默认中国电信（照着电信这条线路天天在跑、按它调的）。移动 / 联通的选项留着，门户上真出现这两家时会用同样的办法去选，但没有长期实测过。

开着时（默认），定时 / 开机 / 重试这类后台自己发起的认证会真的打开门户页：先点「我要下线」+ 确认，等门户注销跳回认证页后把整套认证重做一遍，让时长真正续上。注销后若停在「已下线」页，会自动点「重新入网」回认证页（认不出还会照门户自己的做法直接跳过去）。关掉则退回「已在线就跳过、不碰页面」。

手动操作不受这个开关影响：点弹窗里的「立即认证」、或自己打开认证页时，会先用一次网络探测（约 0.1~0.3 秒）确认设备到底有没有网 —— 真有网就什么都不做（不下线、不重登、不折腾），只有确实没网才动手。这样既不会一打开网页就被下线，也最省电脑资源。

唯一例外：如果探测确认网关正在拦（页面那张「已在线」其实是缓存／假的，设备根本没网），手动操作也会走一遍「下线 → 重新认证」把网络恢复回来 —— 这时下线不影响你正在用的连接，因为本来就没网。

默认只关扩展自己开的页面；认证一有结论就先发通知、再关页面。后者配合计划任务用：任务拉起 Edge → 自动认证 → 标签页自动关掉。

流程全自动：密码框一出现就填 → 自动选中服务商 → 确定。弹「认证失败」会自动重试（最多 3 轮，不用重新登录、也不会重填密码）。

服务选择是独立一整页也没关系：点完「立即登录」会整页跳到 entry/pc/serviceSelection（那一页没有密码框），扩展会把它当独立进场点自动选服务并确定。单选框／标签／卡片／列表都能认；万一卡住，弹窗底部会显示页面诊断和原始 HTML，点一下即可复制。

「成功」判定很严格：必须真出现「认证成功 / 已在线」这类字样，且服务弹窗和「确定」按钮都已消失 —— 页头的「已连接」「注销」不算数。判定不出来时要等网络探测确认，不会在服务没选完时就关页面。

认证页入口

推荐第一项：未认证时网关会带着 sessionId、userIp 等动态参数把浏览器跳到门户登录页。这类门户直接访问刷不出表单（缺参数），「直接打开」只适合地址固定的学校。

只填固定的入口地址；带 sessionId / wlanuserip 这类每次都会变的参数时，请用上面的「让网关自动跳转」。

扩展会依次试多个入口，哪个能刷出登录表单就用哪个，所以这里一般留空就行。只有学校门户必须走某个固定地址时才需要填。

只有 204 才算「真的通了」；被网关跳转、或被回一个 200 拦截页，都算需要认证。每个地址最多等 1.5 秒，连挂两个就收手，不会卡住整轮认证。

教务、图书馆、邮箱这类校内站点也有登录框，可能被误判成门户。扩展已按页面内容自动挡住「教务 / 选课 / 成绩 / 图书 / 一卡通 / 统一身份」这类业务系统；万一还有站点被误伤，把它的域名填这里（写 jwxt.example.edu.cn 只排除它一个；写 example.edu.cn 会把门户也一起排掉，慎用）。

页面元素选择器（可选）

一般不用填。如果自动识别总是填错框，用账号密码框的 id / name 锁死它（F12 可查）。

高级：直接调用登录接口

适合 ajax 接口门户（深澜 Srun、城市热点 Dr.COM）。开启后不打开网页，直接请求接口。

用 {{username}} 和 {{password}} 作为占位符；GET 模式下会拼到 url 后面。
