校园网自动登录 · 设置

扩展平时完全休眠，只在「设定时间点」「浏览器启动时」「打开认证页时」三个时机动作，不做实时轮询。

账号

密码以明文保存在浏览器本地存储中，只在你的电脑上，不会上传。共用电脑请谨慎。

定时认证

到点自动认证，循环执行。建议写上课前、午休后、晚自习这类你需要用网的时刻，2～4 个就够。

1 = 每天（默认）：上面那几个时间点每天都跑一遍。
填 N（>1）就是每 N 天认证一次：上次认证之后，中间 N-1 天直接跳过，到第 N 天的时间点才再跑 —— 给「认证一次能撑好几天」的运营商（移动 / 联通这类）用。
手动点「保存并立即认证一次」和「打开认证页」不受这个周期限制，随时都能触发。

扩展在认证时总会先做一次严格探测：只有检测点返回 204（或两个不同来源都确认通）才认定已联网、跳过认证。打开这个开关后，一个地址回了 2xx 也算数——只有确认你的学校不会屏蔽/伪装探测地址时才开，否则会退回到「明明掉线却说无需认证」的老毛病。

认证方式

默认中国电信：扩展是照着电信这条线路天天在跑的，选服务那一步也是按电信调的。移动 / 联通的选项留着，门户上真出现这两家时扩展会用同样的办法去选，但没有长期实测过，细节可能不一样。

到了认证时间点，如果上一次认证还没到期，门户不会给登录表单，而是直接渲染一张「已在线」成功页（上面有个「我要下线」）。这种情况以前会被当成「本来就在线」跳过，认证时长就一直不续上、下次到点又是在线。打开这个开关后，扩展会先替你把「我要下线」点掉（含确认弹窗），等门户注销完跳回认证页，再把整套认证重做一遍——让认证时长真正从这次开始续上。若注销后门户把你留在「已下线」页，扩展会自动点它的「重新入网」按钮回到认证页；万一门户改版认不出、或点了没反应，还会照门户自己的做法直接跳到它的重新入网地址，所以即使没人去点「重新入网」，认证也一样会进到网页里做完。

配套的一点改动：开着它（默认）时，到点或手动点「保存并立即认证一次」都会真的打开门户网页。以前后台一看网络是通的（认证没到期时必然是通的）就一句「本次无需认证」收手、一个页面都不开，页面脚本连出场的机会都没有，那条续期支路永远跑不到。现在探测只用来找门户地址，不再被当成「无需认证」的结论；已经认证过时还会跳过网关检测地址、直接进门户自己的页面（那个检测地址在已认证状态下只会是一张空白页）。关掉开关则退回旧行为（已在线即跳过，不碰页面、也不开页面）。

默认只关扩展自己开的页面；认证一有结论就先发通知、再关页面，不会挂着不动。后者配合计划任务用：任务拉起 Edge → 扩展自动认证 → 标签页自动关掉，不留垃圾窗口。

流程本身是全自动的：密码框一出现就填账号密码 → 自动识别并选中服务商 → 确定；若弹出「认证失败」提示，会自动点「我知道了」并直接重新点「确定」重试（最多 3 轮，不需要重新登录、也不会重填密码），不需要人工干预。

服务选择是独立一整页也没关系：本门户点完「立即登录」会整页跳到 entry/pc/serviceSelection，那一页没有密码框。扩展把它当成独立的进场点，会自动选中服务商并点「确定」；万一把上面的开关关掉了、页面没动手，后台还会补一次指令。选服务时单选按钮／标签／卡片／列表都能认，认不出结构时还会逐层往上点容器、乃至整页粗搜运营商名字（能点的全点一遍）。万一卡住，弹窗底部会显示页面诊断、页面骨架和一小段原始 HTML，点一下即可复制。

「成功」的判定很严格：必须真的出现「认证成功 / 已在线」这类字样，而且服务选择弹窗和「确定」按钮都已消失——页头挂着「已连接」「注销」这类词不算数。判定不出来时，只有网络探测确认（204）才收尾，绝不会在服务还没选完时就把页面关掉。

认证页入口

推荐第一项：扩展打开一个网络检测地址，未认证时网关会带着 sessionId、userIp、userMac 等参数把浏览器跳到门户登录页。这类门户的登录页直接访问是刷不出表单的（缺参数），所以「直接打开」只适合地址里不含动态参数的学校。两种模式下扩展都会依次试多个入口（含下面的备用入口），一个刷不出表单就换下一个。

只填固定的入口地址；带 sessionId / wlanuserip 这类每次都会变的参数时，请用上面的「让网关自动跳转」。

扩展按「探测到的门户地址 → 网关跳转 → 备用入口 → 认证页地址」依次试，哪个能刷出登录表单就用哪个，所以这里一般留空就行。只有你的学校门户必须走某个固定地址才需要填（不知道填什么就留空）。

只有 204 才算「真的通了」；被网关跳转、或被回一个 200 的拦截页，都算需要认证。（旧版把这种 200 当成已联网，于是明明掉线却说「无需认证」，一个页面都不开。）「让网关自动跳转」模式下会取第一个 http:// 地址作为入口。每个地址最多等 1.5 秒，连挂两个就收手——不会因为某个地址不可达而把整轮认证卡住。

1.13.0 新增。教务系统、图书馆、邮箱这类校内站点同样挂在 .edu.cn 下、同样有登录框，有可能被当成校园网门户：填表提交、弹通知，最后还把网页关掉。扩展已按页面内容自动挡住「教务 / 选课 / 成绩 / 图书 / 一卡通 / 统一身份」这类业务系统；万一还有站点被误伤，把它的域名加到这里（写 jwxt.example.edu.cn 只排除它一个；写 example.edu.cn 会把门户也一起排掉，慎用）。

页面元素选择器（可选）

一般不用填。如果自动识别总是填错框，用账号密码框的 id / name 锁死它（F12 可查）。
